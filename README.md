# Lost and Found System

A simple web-based Lost and Found System that helps users report and find lost or found items.

## Features

* Report lost items
* Report found items
* View lost and found information
* Simple and user-friendly interface
* Deployed using GitHub Pages

## Technologies Used

* HTML
* CSS
* GitHub Pages
